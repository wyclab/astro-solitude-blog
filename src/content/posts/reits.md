> 公募REITs的底层资产信息透明度很高，可以利用公告信息，整理不同底层资产在不同区域的运营情况。

## 初次搭建步骤

### 1. 整理REITs列表，以产业园区入手

在关键环节使用权威数据，因此首先借助Wind数据库，导出全部REITs清单（Excel），其中一列表头是`资产类型`。借助AI，先整理出资产类型和对应个数。如下表：

| 资产类型       |    个数 |
| :------------- | ------: |
| 园区基础设施   |      21 |
| 交通基础设施   |      15 |
| 能源基础设施   |      13 |
| 仓储物流       |      12 |
| 消费基础设施   |      12 |
| 保障性租赁住房 |      11 |
| 商业不动产     |       8 |
| 水利设施       |       2 |
| 生态环保       |       2 |
| 新型基础设施   |       2 |
| 市政设施       |       2 |
| **合计**       | **100** |

上述不同业态的差异比较大，不同业态的底层设施不具备可比性，因此我准备从个数最多的产业园入手。

### 2. 用AI解析一份报告样本，设定数据指标

告诉AI，我想获取产业园的经营数据，我只关心底层资产的运行情况，那么一份REITs季度报告能给我们带来什么信息呢？我们先在[上交所REITs公告](https://www.sse.com.cn/reits/announcements/info/)随便找到一篇产业园区REITs的季度报告，例如[《国泰海通临港创新智造产业园封闭式基础设施证券投资基 金 2026 年第 3 季度报告》](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2026-10-27/508021_20261027_06FE.pdf)，很简单，我们都不需要读它，而是把链接直接丢给AI。然后告诉他：

> 我关注园区基础设施，想了解底层资产的运行情况。请分析这份产业园类 REITs 季度报告（https://www.sse.com.cn/disclosure/fund/announcement/c/new/2026-10-27/508021_20261027_06FE.pdf） ，说明其中可提取的底层资产运营数据，并整理成结构化字段清单，标注字段含义、单位、所属报告期及数据来源位置。随后我需要抓取多个产业园类基础设施基金的底层资产运营数据，进行同一资产跨季度的纵向对比和不同资产之间的横向对比。请据此挑选适用的核心运营指标（如出租率、租金水平、租户结构、收入与现金流等），说明每个指标的选取理由、口径统一方式和可比性处理，并给出适合横向与纵向对比的指标体系。

对话过程中，AI可能会询问你更多的偏好，例如AI可能会反问你比较REITs还是底层项目，只需要按照自己的偏好进行回答：

> 我需要对比的项目唯独，如果一个REITs有多个项目，则需要分别建立底层数据。

总之按照自己的理解对字段进行微调，看了一下AI生成的数据键已经很全面，而且还自己制定了校验规则，所以进入下一步。

### 3. AI爬取全部数据

AI时代并不需要掌握爬虫技术，但最好给AI更清楚的数据来源，只需要用自然语言说：

> 根据此前整理的产业园区REITs清单及指标体系，从深交所（https://www.szse.cn/market/product/list/reits/index.html） 和上交所（https://www.sse.com.cn/reits/announcements/info/） 的公告中爬取对应REITs的定期报告，仅采集标题为“xx年第x季度报告”“xx年年度报告”“xx年中期报告”的文件，忽略临时公告、招募说明书及其他报告。时间范围为2020年1月至今。对每份报告提取指标体系中各项指标数据，标注报告类型、所属报告期及数据来源链接，并按原有指标体系结构入库，完善指标体系数据库；同时说明缺失或无法获取的指标项。

### 4. 搭建网站

底层数据收集完成后，可以直接构建网站/展示面板，同样交给AI，可以找一个喜欢的网站风格让AI学习：

> 我现在要基于这些数据库，搭建一个网站，纯静态，这是我的网站https://xxx.com/ ，保持风格色调一致。 未来的网址是xxx.xxx.com，菜单栏分别是首页（首页是中国地图）、底层资产列表、省份表现。首页地图可以清晰展示不同产业园在国内的地理分布，同时地图上有省界限，点击可以进入省份表现。底层资产列表列出每个底层资产的本期表现，点进去可以查看该底层资产的趋势。 省份表现可以列出该省份底层资产的本期表现，点进去可以查看该省份的趋势。 要求风格简洁美观。
