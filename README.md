# Astro Solitude

一款简洁、优雅、功能丰富的 Astro 博客主题。

## 项目结构

```text
astro-solitude/
├── public/                # 图片、字体等静态资源
├── src/
│   ├── components/        # 主题与 MDX 组件
│   ├── content/
│   │   ├── posts/         # 博客文章
│   │   └── pages/         # 自定义页面
│   ├── data/              # 关于、友链、装备、短文等页面数据
│   ├── layouts/           # 页面布局
│   ├── pages/             # Astro 路由
│   ├── styles/custom.css  # 自定义样式
│   └── site.config.ts     # 站点配置入口
├── docs/                  # 使用文档
└── astro.config.mjs       # Astro 配置
```
