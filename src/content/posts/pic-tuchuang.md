博客里的图一直放在腾讯云 COS 上。Typora的图片上传功能还需要唤醒Picgo等第三方软件，十分冗杂。而且经常出现图片上传失败（文件名字的问题）、图片倒置的问题。

借助AI，干脆给自己定制了一个“图床+图片处理程序”，取名为**六七图床**：[pic.667667.xyz](https://pic.667667.xyz)。

现在传图是：截图 → 拖进浏览器 → 看着体积和尺寸顺眼 → 点上传 → 复制链接，回文章里粘贴。

![Pic 的图片处理页](/img/posts/pic-home.png)

## 它是什么

一个纯静态的单页应用，Vite + React + TypeScript，没有后端。构建产物扔部署在 EdgeOne 上，免费。

左侧三个入口：处理、图库、设置。

**处理**：支持 上传JPG / PNG / WebP / HEIC / GIF，一次最多 60 张，可以点选，也可以直接 粘贴剪贴板里的截图。输出可选原格式，也可以转换成JPEG、WebP、PNG。支持图片压缩的比例，设置最长边（原始尺寸 / 3840 / 2560 / 1920 / 1280）、或者设置目标体积（KB），还有一个“清除 EXIF”的开关，保护图片隐私。所有处理都在本机跑，不经过任何服务器。

**图库**：支持管理COS图库，查看、删除、复制链接等。

**设置**：配置密钥。密钥存在浏览器的 localStorage 里，不会上传到网站。

![Pic 的设置页](/img/posts/pic-settings.png)

它还是个 PWA，可以装到桌面。

## 适合谁

适合有 COS 桶、自己一个人用、不想为传一张图开控制台的人。密钥存在浏览器里，换设备要重新配置。

不适合当公共图床。没有账号体系，没有配额，也没有审计；自己用的工具，够用就行。
