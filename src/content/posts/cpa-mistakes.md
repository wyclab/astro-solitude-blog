## 001 · 无形资产会计处理（多选）

| 项目 | 内容 |
| :--- | :--- |
| 科目 / 章节 | 会计 · 无形资产 |
| 记录日期 | 2026-11-04 |
| 题型 | 多项选择题 |
| 复习状态 | 待复习 |

### 题干

下列关于无形资产会计处理的说法中，正确的有（　　）。

- **A**、投资者投入无形资产的成本，应当按照投资合同或协议约定的价值确定，但合同或协议约定价值不公允的除外
- **B**、企业接受政府补助而取得的无形资产，应按照所取得的无形资产公允价值入账，如果公允价值不能可靠取得，按照名义金额入账
- **C**、企业外购房屋建筑物所支付的价款难以在地上建筑物与土地使用权之间合理分配的，应当全部作为固定资产处理
- **D**、通过非货币性资产交换取得的无形资产，按照公允价值为基础计量

### 正确答案

**A、B、C**

### 解析

通过非货币性资产交换取得的无形资产，要先判断是否具有商业实质：

- **具有商业实质，且换入 / 换出资产的公允价值能够可靠计量**：以公允价值为基础计量；
- **不具有商业实质，或公允价值不能可靠计量**：以换出资产的账面价值为基础计量。

选项 D 直接断言「按照公允价值为基础计量」，漏掉了商业实质与公允价值可靠计量这两个前提，表述绝对，因此错误。

### 考点速记

| 取得方式 | 初始计量基础 |
| :--- | :--- |
| 投资者投入 | 投资合同或协议约定的价值，但约定价值不公允的除外（A） |
| 政府补助取得 | 公允价值；公允价值不能可靠取得的，按名义金额入账（B） |
| 外购房屋建筑物 | 价款难以在地上建筑物与土地使用权之间合理分配的，全部作为固定资产（C） |
| 非货币性资产交换 | 先判商业实质 + 公允价值可靠性，再选公允价值 / 账面价值基础（D 错因） |

> 易错点：看到「公允价值计量」不要直接判对，先想一遍「是否有商业实质、公允价值能否可靠计量」。

## 002 · 在建工程减值损失（单选）

| 项目 | 内容 |
| :--- | :--- |
| 科目 / 章节 | 会计 · 资产减值 |
| 记录日期 | 2026-11-09 |
| 题型 | 单项选择题（计算结果型） |
| 复习状态 | 待复习 |

### 题干

2×24 年 12 月 31 日，丙公司一项在建工程的账面价值为 1350 万元，预计至达到预定可使用状态尚需投入 150 万元。该项目以前未计提减值准备。由于市场出现了与其相类似的项目，丙公司于年末对该项目进行减值测试，经测试表明：

- 扣除继续建造所需投入因素预计未来现金流量现值为 **1110 万元**；
- 未扣除继续建造所需投入因素预计的未来现金流量现值为 **1254 万元**；
- 2×24 年 12 月 31 日，该在建工程项目的市场出售价格减去相关费用后的净额为 **1140 万元**。

则丙公司该在建工程应计提减值损失的金额为（　　）万元。

### 正确答案

**210 万元**

### 解析

第一步，确定可收回金额的「现值」口径。

在建工程尚未完工，账面价值 1350 万元反映的是**当前状态**，并不包含未来还要再投入的 150 万元。因此与之比较的预计未来现金流量现值，必须用**扣除继续建造所需投入**口径的 **1110 万元**；1254 万元含着「再投 150 万后带来的额外现金流入」，与账面价值口径不一致，不能直接比较。

第二步，可收回金额取两者较高者。

> **可收回金额 = max(1140, 1110) = 1140 万元**

第三步，计提减值。

> **1350 − 1140 = 210 万元**

### 考点速记

| 项目 | 金额 | 是否采用 |
| :--- | ---: | :--- |
| 账面价值 | 1350 | 比较基数 |
| 尚需投入 | 150 | 不进账面，也不能用含它的现值 |
| 现值（扣除继续投入） | 1110 | ✅ 采用 |
| 现值（未扣除继续投入） | 1254 | ❌ 干扰项，口径不可比 |
| 公允价值减处置费用净额 | 1140 | ✅ 采用（较高者） |
| 可收回金额 | 1140 | max(1140, 1110) |
| 应计提减值损失 | 210 | 1350 − 1140 |

> 两道坎：① 在建工程的现值要用「扣除继续建造所需投入」口径；② 可收回金额是「现值」与「公允价值减处置费用」中的较高者，不是随便挑一个。

- 错算 96 = 1350 − 1254 → 误用了含继续投入的现值；
- 错算 240 = 1350 − 1110 → 忘了与 1140 比高低。
